# studium-autopilot.github.io

The GitHub Pages site of the Studium Autopilot organisation.

- `datenschutz.md`: the privacy policy of the Studium Autopilot iOS app, published at
  <https://studium-autopilot.github.io/datenschutz/> and linked from the app's settings. It is a copy of `docs/datenschutz.md`
  in the app's repository and changes only together with it.
- `index.md`: the start page.

The central data the app and the Obsidian template read is a separate site, `ecoba-daten`, at
<https://studium-autopilot.github.io/ecoba-daten/>.
